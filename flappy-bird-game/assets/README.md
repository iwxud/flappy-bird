# Куда класть спрайты и звуки

Игра сама определяет, какие файлы присутствуют, и использует их вместо заглушек.
Размеры ниже — рекомендуемые; другие размеры будут масштабированы автоматически.

## assets/sprites/bird/  — птица (3 кадра анимации крыльев)

| Файл                      | Размер    | Описание                    |
|---------------------------|-----------|-----------------------------|
| `yellowbird-upflap.png`   | 44×32     | крыло сверху                |
| `yellowbird-midflap.png`  | 44×32     | крыло посередине            |
| `yellowbird-downflap.png` | 44×32     | крыло снизу                 |

Можно добавить и других птиц (`redbird-*`, `bluebird-*`) — тогда поменяй имена
в функции `AssetsLoader.bird_frames()` (`src/assets_loader.py`).

## assets/sprites/pipes/ — трубы

| Файл             | Размер  | Описание                                   |
|------------------|---------|--------------------------------------------|
| `green_pipe.png` | 70×272  | Одна вертикальная труба «шапкой» вверх. Верхняя часть пары строится отражением. |

## assets/sprites/background/ — фон и земля

| Файл                  | Размер    | Описание                          |
|-----------------------|-----------|-----------------------------------|
| `day_background.png`  | 400×600   | Фон целиком                       |
| `ground.png`          | 400×100   | Тайл земли (повторяется по X)     |

## assets/sprites/ui/ — интерфейс

| Файл                | Размер  | Описание                       |
|---------------------|---------|--------------------------------|
| `scoreboard.png`    | 300×200 | Панель результатов             |
| `button_play.png`   | 100×100 | Кнопка «играть»                |
| `text_gameover.png` | 200×50  | Надпись GAME OVER              |

## assets/fonts/ — шрифты

Положи сюда любой `.ttf` или `.otf` (например `04B_03__.ttf` из оригинала) —
он будет использован для всего текста автоматически.

## assets/sounds/ — звуки (формат .ogg или .wav)

| Файл         | Когда играет                     |
|--------------|---------------------------------|
| `wing.ogg`   | взмах крыльев (пробел/клик)     |
| `score.ogg`  | пролёт трубы (+1 очко)          |
| `hit.ogg`    | столкновение с трубой/землёй    |
| `die.ogg`    | смерть (падение птицы)          |

Все PNG должны быть **с альфа-каналом** (прозрачный фон).
Если какого-то файла нет — вместо него рисуется аккуратная заглушка, игра не сломается.
